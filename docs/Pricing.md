# Commercial pricing (internal / outside repo)

**Purpose:** This repository is shared with interns and contributors. **Do not** put actual prices, discounts, pilot deals, revenue targets, or customer-specific terms in any file tracked here.

---

## Where real numbers live

Maintain authoritative pricing in a **company-private** place only leadership controls, for example:

- Internal wiki / Notion (restricted access)  
- Private spreadsheet  
- CRM or billing tool  

Link that resource internally; do not paste confidential figures into GitHub issues, PRs, or these docs.

---

## Principles (safe to keep in repo)

- Anchor value on **outcomes** (response coverage, qualified leads, time saved), not on “we use AI.”  
- Prefer simple **subscription** mechanics for SMBs until you have enough data for hybrids.  
- Validate willingness to pay with **pilots** before locking tiers.
